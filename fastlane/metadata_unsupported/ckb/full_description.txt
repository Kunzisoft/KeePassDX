KeePassDX <b>بەڕێوەبەر و قاسەیەکی تێپەڕکلیل و تێپەڕوشەی</b> سەرچاوە کراوەیە، ڕێگە بە دەستکاریکردنی <b>داتای پەنهانکراو دەدات لە یەک پەڕگەدا</b> بە فۆرماتی کراوەی KeePass و <b>پڕکردنەوەی فۆڕمەکان بە شێوەیەکی پارێزراو</b>، پێویستی بە <b>هیچ هێڵێکی ئینتەرنێت نییە</b> و ستانداردەکانی ڕووکاری ئەندرۆید لەخۆ دەگرێت. بەرنامەکە <b>سەرچاوە کراوەیە، بەبێ هیچ ڕیکلامێک</b>.

<b>تایبەتمەندییەکان</b>

- تێپەڕکلیلەکان بۆ سەلماندن و هەڵگرتنی ناوخۆیی کلیلە تایبەتەکان.
- ناسینەوەی بایۆمەتری بۆ کردنەوەی خێرا (پەنجەمۆر / کردنەوەی ڕووخسار / …).
- بەڕێوەبردنی تێپەڕوشەی یەکجارەکی (HOTP / TOTP) بۆ سەلماندنی دوو هەنگاوی (2FA).
- پڕکردنەوەی خۆکار بۆ ئاسانکاری پڕکردنەوەی فۆڕمەکان بە تێپەڕوشەکان.
- تەختەکلیلی Magikeyboard بۆ پڕکردنەوەی هەر بوارێک بە شێوەیەکی کارا.
- دروستکردنی پەڕگەی بنکەدراوەی پەنهانکراو.
- ڕێکخستنی بڕواپێکراوەکان بەپێی تۆمار و لە شێوەی درەختی گرووپەکاندا.
- ڕێگە بە کردنەوە و لەبەرگرتنەوەی بوارەکانی URI / URL دەدات بە خێرایی.
- قاڵبە داینامیکییەکان بۆ هەر جۆرێکی تۆمار.
- مێژووی هەر تۆمارێک.
- بەڕێوەبردنی وردی ڕێکخستنەکان.
- دیزاینی ماتێریاڵ لەگەڵ ڕووکارەکان.
- پشتگیری بۆ پەڕگەکانی .kdb و .kdbx (وەشانی ١ بۆ ٤) بە ئەلگۆریتمەکانی AES - Twofish - ChaCha20 - Argon2.
- گونجاوە لەگەڵ زۆربەی بەرنامە جێگرەوەکاندا (KeePass, KeePassXC, KeeWeb, …).
- کۆدەکان بە زمانە ڕەسەنەکان نووسراون (Kotlin / Java / JNI / C).

دەتوانیت کۆمەک بکەیت یان وەشانی پڕۆ (Pro) بکڕیت بۆ خزمەتگوزارییەکی باشتر و پەرەپێدانی خێرای ئەو تایبەتمەندییانەی دەتەوێت: <a href="https://play.google.com/store/apps/details?id=com.kunzisoft.keepass.pro">https://play.google.com/store/apps/details?id=com.kunzisoft.keepass.pro</a>
