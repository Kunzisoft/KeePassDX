KeePassDX — це застосунок із відкритим кодом для <b>керування ключами доступу та паролями й безпечного їх зберігання</b>, який дає змогу редагувати <b>зашифровані дані в одному файлі</b> у відкритому форматі KeePass та <b>безпечно заповнювати форми</b>. Він <b>не потребує підключення до Інтернету</b> та відповідає стандартам дизайну Android. Застосунок має <b>відкритий код і не містить реклами</b>.

<b>Можливості</b>

- Ключі доступу (Passkeys) для автентифікації та локального зберігання приватних ключів.
- Біометричне розпізнавання для швидкого розблокування (відбиток пальця / розпізнавання обличчя / …).
- Керування одноразовими паролями (HOTP / TOTP) для двофакторної автентифікації (2FA).
- Автозаповнення для зручного заповнення форм паролями.
- Magikeyboard для ефективного заповнення будь-яких полів.
- Створення зашифрованих файлів баз даних.
- Організація облікових даних у вигляді записів і дерев груп.
- Можливість швидко відкривати та копіювати поля URI / URL.
- Динамічні шаблони для кожного типу записів.
- Історія змін кожного запису.
- Гнучке керування налаштуваннями.
- Material Design із підтримкою тем.
- Підтримка файлів .kdb і .kdbx (версії від 1 до 4) з алгоритмами AES, Twofish, ChaCha20 та Argon2.
- Сумісність із більшістю альтернативних програм (KeePass, KeePassXC, KeeWeb, …).
- Код написано нативними мовами та технологіями (Kotlin / Java / JNI / C).
